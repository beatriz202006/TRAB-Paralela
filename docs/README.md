# LCS - Programação Paralela

Trabalho prático de Programação Paralela utilizando OpenMP e MPI.

## Objetivo
Implementar uma versão paralela do algoritmo LCS
(Longest Common Subsequence), comparando seu desempenho
com a implementação sequencial.

## Estrutura
- src/sequential: implementação sequencial.
- src/parallel: implementação paralela.
- inputs: arquivos de entrada.
- scripts: scripts de execução e testes.
- results: resultados experimentais.
- docs: documentação e relatório.

## Tecnologias
- Linguagem C
- OpenMP
- MPI
- Git e GitHub
